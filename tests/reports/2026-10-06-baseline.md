# Baseline test run: October 6, 2026

First run of the suite against `main` at `fb1bca7` (identical to the live site).
Browser results are from Chrome desktop (1440px) and an Android-size phone (Pixel 7).
Safari, iPhone, iPad and Firefox were not run in this pass (their engines could not
be downloaded in the session's sandbox); run `npm test` on the Mac to cover them.
Live checks were run by hand in a real browser on the Mac.

**Totals:** static checks 44 FAIL, 44 WARN. Browser: 64 of 339 Chromium test runs
fail, 275 pass (two identical runs, no flaky tests). Live: 2 FAIL (security headers).

## What passed

14 widths from 320px to 1920px; nothing loops and motion settles; reduced motion shows
the finished page at once; layout shift under 0.1; every Tab stop has a visible focus

with JavaScript off. Live: every page 200 and matching the build, one URL per page, a
real 404, retired URLs, `http`, `www` and `sprysafe.com` all redirect correctly,
analytics beacon present, MX, SPF and DMARC in place, booking link and sources load.
